## Authored Sage home pack

The Arena-only Sage pilot uses an original, AI-assisted puppet master derived
from the approved Sage reference, not a downloaded franchise sprite. The six
original collection/combat paintings and stable fighter IDs are unchanged.

- `assets/images/fighters/home/sage-source.png`: 1254-square source sheet.
- `sage-atlas.png`: 1536-square RGBA atlas, thirteen separated pieces: body,
  six skin-only head views/expressions, three forearm/hand drawings, coat tail,
  star and stationary foreground collar.
- `sage-rest.png`: 560 x 1000 RGBA baked rest for loading/reduced motion.
- `src/assets/sage-performance.json`: sprite bounds, connection anchors and
  the anatomical neck socket. The source heads' duplicate collars are removed;
  the torso's foreground collar paints above the head/neck overlap, both live
  and in the baked poster. The exposed socket is repainted as a neck bridge.

Rebuild with `python scripts\build-sage-performance.py`. Keep source-specific
anchors and body/head/foreground-collar paint order synchronized; changing only the live head position
would reintroduce a different neck in reduced motion. The existing Skia player
shares one texture/canvas; the atlas is 9 MiB decoded before cache/GPU overhead.
No Spine/3D dependency or runtime license was added. The other five home packs
and physical-device memory/performance acceptance remain open.

The original containment pack under `assets/images/chests/containment/` contains
one 1536 x 384 RGBA vapor atlas and four shell-alpha seam mattes. Three tapered
silhouettes have distinct internal light/shadow and safe transparent edges.
`src/assets/containment.ts` supplies static local sources. Rebuild with
`python scripts\build-containment-art.py` using the existing NumPy/Pillow tools.
The atlas alone is 2.25 MiB decoded; this is not measured native GPU memory/FPS
acceptance. The runtime shader clamps each sprite's sampling to its own region.

The current chest state images are transparent modern tech-shell designs:
Field 615 x 300, Arc 615 x 310, Overdrive 615 x 310, Sovereign 615 x 358.
Their prior strap/arch/royal-trim artwork is superseded. Brand assets rebuild
with `python scripts/build-brand-assets.py`; font outlines remain local.

Rebuild the ritual backdrop and grayscale paintings with
`node scripts/build-chest-ritual.cjs`. This derives the scene from the existing
Experience Board and preserves the original painted Brawler alpha; it adds no
new generated art or runtime graphics context.

The earlier 16 segmented chest layers, registry and
`scripts/build-chest-layers.py` are retained as a superseded study, not the live
opening renderer. The user-selected section 06 closed/open paintings and timing
are now the active visual contract.

## Retained historical resources

The previous raster fighters, Mystic Arena image, old vector `FighterRig`,
skeletal reference geometry and import script are retained as historical
resources. The active character renderers no longer draw the mascot-like rigs;
the reference action metadata still supplies cosmetic contact timing. The flat
human vector substitute is also retired from the active renderer. Earlier phase
screenshots and APKs are not evidence of this new artwork or fixed-page UX.

No changes to saved IDs, inventory, passives, damage, timers, progression,
capsule probabilities or duplicate conversion accompany the artwork change.
After editing a source Brawler painting, regenerate both painted coverage and
fragment anchors, then rebuild the portable study. The old fall sampler remains
historical reference math; live and native-preview presentations use vaporization.
See [art direction](ART_DIRECTION.md) and [the design system](VOLT_DESIGN_SYSTEM.md).
Native iOS/Android device acceptance remains open.
